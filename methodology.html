How we work

Methodology and editorial policy

ModelMetric Lab is built around transparent calculations: show the formula, expose the assumptions, test the arithmetic, and explain where the result stops being reliable.

How calculators are built

Each calculator starts with a narrow question and a documented formula. Inputs are labeled in the units users actually provide, defaults are illustrative rather than provider endorsements, and outputs show enough detail to reproduce the result.

How formulas are checked

We compare worked examples against hand calculations, test boundary cases such as zero denominators and empty text, and run the site's automated regression checks before publishing. When a formula is an approximation, the interface and guide say so directly.

How changing prices are handled

Provider pricing is kept as user-editable input rather than hard-coded as a timeless fact. When we publish a source note, it includes the provider, page, retrieval date, and the scope of the rate. See the pricing sources and changelog for the current record.

Editorial standards

  • Prefer primary documentation and first-party pricing pages.
  • Separate measured facts, assumptions, and illustrative examples.
  • Update or annotate pages when important inputs change.
  • Do not publish thin pages whose only purpose is to target a keyword.
  • Correct errors openly and keep the explanation understandable.

Last reviewed
