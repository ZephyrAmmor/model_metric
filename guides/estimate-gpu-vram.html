How to estimate GPU VRAM for an AI model

Start with the raw memory needed for model weights, then add a realistic overhead factor. Do not confuse this with a complete training or inference memory model.

Weight-memory formula

weight bytes ≈ parameter count × bytes per parameter

Since one byte is eight bits, a 7-billion-parameter model at 16-bit precision needs about 14 billion bytes just for the weights. That is roughly 13 GiB in binary units before runtime overhead.

Precision changes the footprint

At the weights-only level, 8-bit uses about half the storage of 16-bit, while 4-bit uses about one quarter. Real systems can be more complicated because quantization formats may have metadata and because runtime memory is not only the weights.

Inference adds other memory

During generation, memory can also be consumed by the KV cache, activations, temporary buffers, framework/runtime allocations, batching, sequence length, and other implementation details. The right amount of free VRAM therefore depends on the workload, not just the parameter count.

Training is a different problem

Training can require substantially more memory because of gradients, optimizer states, activations, and checkpointing. A weights-only calculator should never be treated as a training-capacity guarantee.
